# Part 4 — Retention Intelligence & Dashboard

Run dashboard: `streamlit run app.py`. The dashboard combines churn probabilities and CLV estimates, ranks customers using a transparent risk/value/cost heuristic, and exports recommendations.

The save-rate is a user-entered scenario assumption. It is not learned from this dataset. Causal/uplift analysis requires historical treatment/control assignment and outcomes; no causal claim is made from the Telco snapshot.
