# DS-01 Project Map — Parts 1–5

- Part 1: Data collection, validation, cleaning, EDA and feature engineering (`src/run_part1.py`, `src/run_eda.py`).
- Part 2: Churn prediction with Logistic Regression/LightGBM, evaluation and inference (`src/train_churn_model.py`, `src/predict_churn.py`).
- Part 3: Kaplan–Meier survival analysis and discounted CLV estimation (`src/clv_model.py`).
- Part 4: Retention prioritization and scenario economics (`src/retention.py`, legacy Part 4 UI preserved in `app_part4.py`).
- Part 5: Interactive customer intelligence dashboard (`app.py`, `src/dashboard_utils.py`).

Main dashboard command: `streamlit run app.py`.
Legacy Part 4 dashboard command: `streamlit run app_part4.py`.
